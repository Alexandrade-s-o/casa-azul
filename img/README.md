# Imágenes

Coloca aquí el logo de Casa Azul con el nombre exacto:

```
img/casa-azul-logo.jpg
```

(También sirve `.png`; si usas otra extensión, cambia la ruta en `index.html`.)

La web lo recorta automáticamente en círculo con CSS (`object-fit: cover`
+ `border-radius: 50%`), así que no necesitas editar la imagen: las esquinas
oscuras quedan fuera del círculo.
